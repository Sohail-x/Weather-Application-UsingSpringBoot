# 🌤️ Weather API Full-Stack Application

A full-stack web application designed to fetch and display weather information using a Java Spring Boot REST API backend and a lightweight HTML/CSS/JavaScript frontend.

---

## 📁 Project Structure

```text
├── backend/          # Spring Boot REST API Application
└── frontend/         # HTML, CSS, and JavaScript UI


  🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (Fetch API)
Backend: Java, Spring Boot, REST APIs
Tools Used: VS Code, Git, GitHub

✨ Features
Real-time Weather Data: Interactive UI communicating with backend endpoints.

Decoupled Architecture: Clean separation between frontend and backend services.

CORS Configured: Smooth API communication between ports (localhost:8080 & localhost:5500).

🚀 Getting Started
Prerequisites
Java JDK 17+

Maven (optional, if running via command line)

VS Code with Live Server extension

Setup & Installation
1. Backend (Spring Boot)
Navigate to the backend directory:

Bash
cd backend
Run the application using Maven:

Bash
./mvnw spring-boot:run
Backend server will start on http://localhost:8080

2. Frontend (HTML/CSS/JS)
Open the frontend folder in VS Code.

Right-click on index.html and select Open with Live Server.
Frontend UI will run on http://127.0.0.1:5500
